# Frontend Practice

HTML, CSS, and JavaScript practice from my web development journey, plus a Spotify clone project.

## What's inside

| Folder       | Contents |
| `HTML & CSS` | Forms, images, and page styling (`index.html`, `index1.html`, `style.css`) |
| `JavaScript` | Core JavaScript (`basics.js`, `advance.js`) and DOM manipulation (`dom.js`) |
| `Projects/Spotify Clone` | A Spotify-style music player UI (`miniproject.html`, `project.css`) |

## Tech
HTML, CSS, JavaScript

## How to run
No install needed. Open any `.html` file in your browser. For the Spotify clone, open `Projects/Spotify Clone/miniproject.html`.
