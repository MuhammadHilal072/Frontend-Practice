# Frontend Practice

HTML, CSS, and JavaScript practice from my web development journey.

## What's inside

| Folder / File | Contents |
| `index.html`  | Sign-in and sign-up form practice at the repo root |
| `HTML & CSS/` | Forms, images, and page styling (`index.html`, `index1.html`, `style.css`), including a Bootstrap-styled page |
| `JavaScript/` | Core JavaScript (`basics.js`), DOM manipulation (`dom.js`), asynchronous JavaScript (`advance.js`), and a demo page (`index.html`, `style.css`) |

## Topics covered

**HTML and CSS**
- Page structure, forms, and input types
- Images and layout
- Styling with CSS selectors
- Bootstrap components

**JavaScript fundamentals (`basics.js`)**
- Template literals and operators
- Conditional statements, logical operators, and switch statements
- Alerts, prompts, and errors
- String methods and method chaining
- Arrays: methods, references, constant arrays, and nested arrays
- Loops: `for`, nested loops, `for...of`, and looping over arrays
- Objects: literals, nested objects, and objects with arrays
- The `Math` object and random number generation
- Functions: arguments, scope, function expressions, and higher-order functions
- Mini projects: a To-Do app and a Guessing Game

**DOM manipulation (`dom.js`)**
- Query selectors
- Changing content, attributes, and styles (`style` and `classList`)
- DOM navigation (parent, children, siblings)
- Adding and removing elements
- Events and event listeners, including `this` with listeners
- Keyboard, form, change, and input events
- Extracting data from forms
- Event bubbling
- Mini projects: a Text Editor and a To-Do app

**Asynchronous JavaScript (`advance.js`)**
- The call stack and breakpoints for debugging
- Synchronous and asynchronous behavior
- Callbacks and callback hell
- Promises: `then()`, `catch()`, and promise chaining
- Async functions

## Tech

HTML, CSS, JavaScript, Bootstrap

## How to run

No install needed. Open any `.html` file in your browser.

For the JavaScript examples, open `JavaScript/index.html`, then press F12 and check the Console tab. Many examples are commented out, so uncomment the section you want to try.
